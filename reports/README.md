# Generated Reports | التقارير الناتجة من الكود

<!-- BILINGUAL:EN -->
<!-- BILINGUAL:AR -->

لا توجد قوالب يدوية مطلوبة. تنشئ اللابات الملفات اللازمة تلقائيًا.

المخرجات النهائية المتوقعة:

```text
reports/MODEL_CARD.md
reports/ENSEMBLE_DECISION.md
```

قد تنشئ الأيام السابقة تقارير تفسير أو قرار إضافية. احتفظ بالملفات الناتجة كما هي، وأضف تفسيرك المختصر داخل README وإجابة سؤال اليوم.

The labs generate the required final reports. Learners do not complete separate manual report templates; they preserve the generated files and add one short daily explanation to README.

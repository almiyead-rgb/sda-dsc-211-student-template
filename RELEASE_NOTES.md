# v1.1.0 Learner workflow update | تحديث مسار المتدرب

<!-- BILINGUAL:EN -->
<!-- BILINGUAL:AR -->

The learner workflow is simplified around daily Colab execution and one integrated final project.

## Changes

- No mandatory presentation.
- No manually completed report templates.
- One simple question at the end of each daily learning step.
- Same-day upload of the executed notebook and key generated outputs.
- `DAILY_LEARNING_PATH.md` provides the five-day instructions.
- `EXPECTED_RESULTS.md` shows reference file names, row counts and readiness states.
- Day 5 exports the integrated project.
- Notebook 99 and Final Project Check are used before one formal grading cycle.
- The project score remains **100 points: 80 technical + 20 administrative**.
- Attendance separately controls certificate eligibility; the completion threshold remains **70**.

## بالعربية

أصبح المسار قائمًا على لاب يومي في Colab، ورفع يومي للدفتر والمخرجات، وإجابة سؤال واحد، ثم مشروع متكامل يصدر في اليوم الخامس. أُلغي العرض الإلزامي وقوالب التقارير اليدوية. يراجع المتدرب النتائج المرجعية قبل تشغيل **دفتر 99** والفحص النهائي والتصحيح مرة واحدة.

درجة المشروع **100 درجة: 80 للمتطلبات التقنية و20 للمتطلبات الإدارية**، ويبقى الحضور شرطًا مستقلًا لاستحقاق الشهادة، وحد الاجتياز 70 درجة.
